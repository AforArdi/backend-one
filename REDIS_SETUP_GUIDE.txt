1. WHAT IS REDIS?
================================================================================

Redis = Remote Dictionary Server

Simple definition: A fast, in-memory database that stores key-value pairs.

Why use Redis for this project?
- Store temporary OTP codes (expire after 5-10 minutes)
- Queue messages for sending
- Cache user data
- Session management
- Real-time notifications

Key features:
✓ Super fast (in-memory)
✓ Automatic expiration (set TTL on keys)
✓ Data types: strings, lists, sets, hashes, sorted sets
✓ Pub/Sub for real-time messaging

FILE: docker-compose.yaml
---
services:
  redis:
    image: redis:7-alpine
    container_name: rise-together-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 5
    restart: unless-stopped

  app:
    container_name: rise-together-backend
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "${PORT:-5000}:${PORT:-5000}"
    env_file:
      - .env
    depends_on:
      redis:
        condition: service_healthy
    restart: unless-stopped

volumes:
  redis_data:
---

Explanation of Redis config:
- image: redis:7-alpine → Latest Redis on Alpine (lightweight)
- ports: "6379:6379" → Default Redis port
- volumes: Persists data to disk
- command: --appendonly yes → Append-only file (saves data on disk)
- healthcheck: Ensures Redis is ready before app starts
- depends_on: Makes app wait for Redis

Update your .env file:
---
REDIS_URL=redis://redis:6379/0
---

NOTE: When running locally with Docker Compose:
- Redis hostname is "redis" (service name)
- Port is 6379 (default)
- Full URL: redis://redis:6379/0

When running OUTSIDE Docker (localhost development):
- REDIS_URL=redis://localhost:6379/0

import { createClient } from 'redis';
import { env } from './env.js';

let redisClient: ReturnType<typeof createClient> | null = null;

export const getRedisClient = async () => {
  if (redisClient) {
    return redisClient;
  }

  redisClient = createClient({
    url: env.redisUrl,
  });

  redisClient.on('error', (err) => console.error('Redis Client Error:', err));
  redisClient.on('connect', () => console.log('Redis Connected'));

  await redisClient.connect();

  return redisClient;
};

export const disconnectRedis = async () => {
  if (redisClient) {
    await redisClient.quit();
    redisClient = null;
  }
};

5. TEST OTP SENDING WITH REDIS
================================================================================

Create: src/services/otp.service.ts

---FILE: src/services/otp.service.ts---

import { getRedisClient } from '../config/redis.js';

const OTP_EXPIRY_SECONDS = 600; // 10 minutes

// Generate random 6-digit OTP
export const generateOTP = (): string => {
  return Math.floor(100000 + Math.random() * 900000).toString();
};

// Store OTP in Redis with expiry
export const storeOTP = async (email: string, otp: string): Promise<void> => {
  const redis = await getRedisClient();
  const key = `otp:${email}`;
  
  // SET key value EX seconds
  await redis.setEx(key, OTP_EXPIRY_SECONDS, otp);
  
  console.log(`OTP stored for ${email}: ${otp} (expires in ${OTP_EXPIRY_SECONDS}s)`);
};

// Verify OTP from Redis
export const verifyOTP = async (email: string, otp: string): Promise<boolean> => {
  const redis = await getRedisClient();
  const key = `otp:${email}`;
  
  const storedOTP = await redis.get(key);
  
  if (!storedOTP) {
    console.log(`OTP expired or not found for ${email}`);
    return false;
  }
  
  const isValid = storedOTP === otp;
  
  if (isValid) {
    // Delete OTP after verification (one-time use)
    await redis.del(key);
    console.log(`OTP verified and deleted for ${email}`);
  }
  
  return isValid;
};

// Get remaining TTL (time-to-live)
export const getOTPTTL = async (email: string): Promise<number> => {
  const redis = await getRedisClient();
  const key = `otp:${email}`;
  
  const ttl = await redis.ttl(key);
  return ttl; // -1 if no expiry, -2 if key doesn't exist
};

---END FILE---

import { Router, Request, Response } from 'express';
import { generateOTP, storeOTP, verifyOTP, getOTPTTL } from '../services/otp.service.js';
import { sendEmail } from '../services/mail.service.js';

const otpRouter = Router();

// Endpoint 1: Request OTP (send to email)
otpRouter.post('/request-otp', async (req: Request, res: Response) => {
  try {
    const { email } = req.body;

    if (!email) {
      return res.status(400).json({ message: 'Email required' });
    }

    // Generate OTP
    const otp = generateOTP();

    // Store in Redis
    await storeOTP(email, otp);

    // Send via email
    await sendEmail({
      to: email,
      subject: 'Your OTP Code',
      html: `
        <h2>OTP Verification</h2>
        <p>Your OTP code is: <strong>${otp}</strong></p>
        <p>This code expires in 10 minutes.</p>
      `,
    });

    res.status(200).json({
      message: 'OTP sent to email',
      email,
      // Remove in production! Only for testing:
      otp_for_testing: otp,
    });
  } catch (error) {
    console.error('Error requesting OTP:', error);
    res.status(500).json({ message: 'Failed to send OTP' });
  }
});

// Endpoint 2: Verify OTP
otpRouter.post('/verify-otp', async (req: Request, res: Response) => {
  try {
    const { email, otp } = req.body;

    if (!email || !otp) {
      return res.status(400).json({ message: 'Email and OTP required' });
    }

    const isValid = await verifyOTP(email, otp);

    if (isValid) {
      return res.status(200).json({
        message: 'OTP verified successfully',
        verified: true,
      });
    } else {
      return res.status(401).json({
        message: 'Invalid or expired OTP',
        verified: false,
      });
    }
  } catch (error) {
    console.error('Error verifying OTP:', error);
    res.status(500).json({ message: 'Failed to verify OTP' });
  }
});

// Endpoint 3: Check OTP TTL (for debugging)
otpRouter.get('/otp-ttl/:email', async (req: Request, res: Response) => {
  try {
    const { email } = req.params;

    const ttl = await getOTPTTL(email);

    res.status(200).json({
      email,
      ttl_seconds: ttl,
      message: ttl > 0 ? `OTP expires in ${ttl} seconds` : 'No OTP found',
    });
  } catch (error) {
    console.error('Error checking TTL:', error);
    res.status(500).json({ message: 'Failed to check TTL' });
  }
});

Create: src/services/message-queue.service.ts

---FILE: src/services/message-queue.service.ts---

import { getRedisClient } from '../config/redis.js';

interface MessageJob {
  to: string;
  subject: string;
  html: string;
  timestamp: number;
  attempt: number;
}

const MESSAGE_QUEUE_KEY = 'message:queue';
const PROCESSING_KEY = 'message:processing';

// Add message to queue
export const queueMessage = async (
  to: string,
  subject: string,
  html: string
): Promise<void> => {
  const redis = await getRedisClient();

  const job: MessageJob = {
    to,
    subject,
    html,
    timestamp: Date.now(),
    attempt: 0,
  };

  // Push to queue (FIFO - First In First Out)
  await redis.lPush(MESSAGE_QUEUE_KEY, JSON.stringify(job));

  console.log(`Message queued for ${to}`);
};

// Get next message from queue (non-blocking)
export const getNextQueuedMessage = async (): Promise<MessageJob | null> => {
  const redis = await getRedisClient();

  // POP from right (gets oldest message first)
  const jobData = await redis.rPop(MESSAGE_QUEUE_KEY);

  if (!jobData) {
    return null;
  }

  return JSON.parse(jobData);
};

// Get queue length
export const getQueueLength = async (): Promise<number> => {
  const redis = await getRedisClient();
  const length = await redis.lLen(MESSAGE_QUEUE_KEY);
  return length;
};

// Get all queued messages (for debugging)
export const getAllQueuedMessages = async (): Promise<MessageJob[]> => {
  const redis = await getRedisClient();

  // LRANGE key 0 -1 (gets all items)
  const items = await redis.lRange(MESSAGE_QUEUE_KEY, 0, -1);

  return items.map(item => JSON.parse(item));
};

// Mark message as processing
export const markMessageProcessing = async (jobId: string): Promise<void> => {
  const redis = await getRedisClient();
  
  // Store for 1 hour (3600 seconds) for tracking
  await redis.setEx(PROCESSING_KEY + ':' + jobId, 3600, 'processing');
};

// Clear message from processing
export const clearMessageProcessing = async (jobId: string): Promise<void> => {
  const redis = await getRedisClient();
  await redis.del(PROCESSING_KEY + ':' + jobId);
};

---END FILE---

Create: src/routes/message.route.ts

---FILE: src/routes/message.route.ts---

import { Router, Request, Response } from 'express';
import {
  queueMessage,
  getQueueLength,
  getAllQueuedMessages,
  getNextQueuedMessage,
} from '../services/message-queue.service.js';
import { sendEmail } from '../services/mail.service.js';

const messageRouter = Router();

// Endpoint 1: Queue a message (add to Redis queue)
messageRouter.post('/queue', async (req: Request, res: Response) => {
  try {
    const { to, subject, html } = req.body;

    if (!to || !subject || !html) {
      return res.status(400).json({
        message: 'to, subject, and html are required',
      });
    }

    await queueMessage(to, subject, html);

    res.status(200).json({
      message: 'Message queued successfully',
      to,
      subject,
    });
  } catch (error) {
    console.error('Error queuing message:', error);
    res.status(500).json({ message: 'Failed to queue message' });
  }
});

// Endpoint 2: Get queue length (how many messages waiting)
messageRouter.get('/queue-length', async (req: Request, res: Response) => {
  try {
    const length = await getQueueLength();

    res.status(200).json({
      queue_length: length,
      message: `${length} message(s) in queue`,
    });
  } catch (error) {
    console.error('Error getting queue length:', error);
    res.status(500).json({ message: 'Failed to get queue length' });
  }
});

// Endpoint 3: Get all queued messages (debugging)
messageRouter.get('/queue-all', async (req: Request, res: Response) => {
  try {
    const messages = await getAllQueuedMessages();

    res.status(200).json({
      count: messages.length,
      messages,
    });
  } catch (error) {
    console.error('Error getting queued messages:', error);
    res.status(500).json({ message: 'Failed to get queued messages' });
  }
});

// Endpoint 4: Process one message from queue
messageRouter.post('/process-one', async (req: Request, res: Response) => {
  try {
    const job = await getNextQueuedMessage();

    if (!job) {
      return res.status(400).json({
        message: 'No messages in queue',
      });
    }

    // Send email
    await sendEmail({
      to: job.to,
      subject: job.subject,
      html: job.html,
    });

    res.status(200).json({
      message: 'Message sent successfully',
      to: job.to,
      subject: job.subject,
      sent_at: new Date().toISOString(),
    });
  } catch (error) {
    console.error('Error processing message:', error);
    res.status(500).json({ message: 'Failed to process message' });
  }
});

// Endpoint 5: Process all queued messages
messageRouter.post('/process-all', async (req: Request, res: Response) => {
  try {
    let processed = 0;
    let failed = 0;

    while (true) {
      const job = await getNextQueuedMessage();

      if (!job) break;

      try {
        await sendEmail({
          to: job.to,
          subject: job.subject,
          html: job.html,
        });
        processed++;
      } catch (error) {
        console.error(`Failed to send to ${job.to}:`, error);
        failed++;
      }
    }

    res.status(200).json({
      message: 'Batch processing complete',
      processed,
      failed,
    });
  } catch (error) {
    console.error('Error processing all messages:', error);
    res.status(500).json({ message: 'Failed to process all messages' });
  }
});

export default messageRouter;

---END FILE---

9. COMMON REDIS COMMANDS
================================================================================

Access Redis CLI from container:
---
docker exec -it rise-together-redis redis-cli
---

Basic commands:

SET / GET (store & retrieve):
---
SET mykey "hello"
GET mykey
# Returns: "hello"
---

SETEX (set with expiry):
---
SETEX mykey 60 "hello"  # expires in 60 seconds
TTL mykey  # check remaining time
# Returns: 59, 58, 57, ... then -2 when expired
---

DEL (delete key):
---
DEL mykey
---

EXISTS (check if key exists):
---
EXISTS mykey
# Returns: 1 (exists) or 0 (doesn't exist)
---

KEYS (find all keys):
---
KEYS *  # Lists all keys
KEYS otp:*  # Lists all OTP keys
KEYS message:*  # Lists all message keys
---

LPUSH / RPUSH (add to list):
---
LPUSH mylist "first"
LPUSH mylist "second"
# List now: [second, first]
---

LPOP / RPOP (remove from list):
---
LPOP mylist  # removes from left
RPOP mylist  # removes from right
---

LLEN (list length):
---
LLEN mylist
---

LRANGE (get range from list):
---
LRANGE mylist 0 -1  # all items
LRANGE mylist 0 2   # first 3 items
---

FLUSH (delete all):
---
FLUSHDB  # delete all keys in current database
FLUSHALL  # delete all databases
---

DBSIZE (how many keys):
---
DBSIZE  # returns number of keys
---

INFO (Redis stats):
---
INFO  # detailed stats
INFO server  # only server info
---

MONITOR (watch commands in real-time):
---
MONITOR  # shows all commands being executed
---

Exit Redis CLI:
---
EXIT
or
QUIT
---

10. TROUBLESHOOTING
================================================================================

Issue 1: "Failed to connect to Redis"
---
Cause: Redis container not running

Solution:
docker compose up -d  # Make sure Redis is started
docker compose ps     # Check status
docker compose logs rise-together-redis  # Check Redis logs

Check REDIS_URL is correct:
- Local: redis://localhost:6379/0
- Docker: redis://redis:6379/0 (service name, not localhost)
---

Issue 2: "Connection refused on port 6379"
---
Cause: Port conflict or Redis crashed

Solution:
docker compose down -v  # Remove everything
docker compose up -d --build  # Rebuild fresh
---

Issue 3: "OTP stored but verification fails"
---
Cause: OTP may have expired or typo in verification

Solution:
Check TTL: curl http://localhost:5000/api/v1/otp-ttl/:email
Check Redis directly: docker exec -it rise-together-redis redis-cli GET otp:email@test.com
---

Issue 4: "Message queue not sending"
---
Cause: Email service misconfigured or queue empty

Solution:
Check queue length: curl http://localhost:5000/api/v1/messages/queue-length
Check queued messages: curl http://localhost:5000/api/v1/messages/queue-all
Check app logs: docker compose logs rise-together-backend
---

Issue 5: "Redis data persists but I want fresh data"
---
Cause: Append-only file saves data to disk

Solution:
docker compose down -v  # -v removes volumes (deletes all Redis data)
docker compose up -d  # Starts fresh with empty Redis
---

Issue 6: "Out of memory errors"
---
Cause: Redis ran out of RAM

Solution:
Check Redis memory usage:
docker exec rise-together-redis redis-cli INFO memory

Increase memory limit in docker-compose.yaml:
deploy:
  resources:
    limits:
      memory: 512M  # or more

Clear old data:
docker exec rise-together-redis redis-cli FLUSHDB
---

Issue 7: "Slow Redis performance"
---
Cause: Too much data or inefficient queries

Solution:
Monitor commands: docker exec -it rise-together-redis redis-cli MONITOR
Check database size: docker exec -it rise-together-redis redis-cli DBSIZE
Profile slowlog: docker exec -it rise-together-redis redis-cli SLOWLOG GET 10
---

Issue 8: ".env file not loading REDIS_URL"
---
Cause: Typo in .env or env.validation not parsing

Solution:
Check .env file exists in project root
Check REDIS_URL format: redis://host:6379/0
Rebuild Docker image: docker compose build --no-cache
Check validation: pnpm run type-check
---
